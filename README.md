# LEGO Collection Tracker 🧱

A beginner-friendly React project using Vite. Practice JSX, components, props, useState, events, list rendering, and conditional rendering.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the URL shown in your terminal.

## Try these challenges

1. Add another LEGO set to the `legoSets` array in `src/App.jsx`.
2. Change the heading and colors.
3. Add a button that clears the entire collection.
4. Add a filter to show only collected sets.

Note: Your collection is kept in React state and resets when the page reloads. Saving it to localStorage is a good next lesson.
